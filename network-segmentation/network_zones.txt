# Define your network zones and forbidden cross-zone access patterns.
#
# Format: ZONE_NAME | IP_RANGE | SECURITY_LEVEL
#
# Zones:
#   - IT: Corporate/enterprise network
#   - DMZ: Demilitarized zone between IT and OT
#   - OT: Operational technology / industrial network
#   - SAFETY: Safety instrumented systems (SIS)
#
# The hook prevents direct access from IT to OT/SAFETY zones.
# =============================================================================

# --- Forbidden cross-zone patterns ---
# Format: SOURCE_ZONE -> TARGET_ZONE | REASON
# IT -> OT | Direct IT-to-OT access violates ISA/IEC 62443 zone model
# IT -> SAFETY | Direct IT-to-SAFETY access is strictly forbidden
# OT -> IT | OT-to-IT access should go through DMZ
# ANY -> SAFETY | Only certified safety controllers should access SAFETY zone
